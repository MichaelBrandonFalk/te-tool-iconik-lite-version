Download the plug-and-play Mac app

The desktop app is the main tool: open it, install it to Applications if macOS launched it from a temporary folder, save AWS and Iconik credentials in Settings, use Test Iconik to confirm the API connection, choose or save a QC profile, paste an S3 bucket, folder, file path, or Iconik link, then click Scan. It lists each video, retrieves Iconik metadata, applies the active profile, and writes the pastel-coded XLSX report.

Metadata Signals

V1.10 Default Checks

The default profile is VOD Technical Delivery Specification 2026_09_17: .mov or accepted high-bitrate .mp4, ProRes or native MP4 codec metadata, HD 1920x1080 or SD at least 480p, HD 16:9 or SD 4:3, pixel aspect ratio 1:1, progressive scan, SDR Rec.709, stereo 2.0 audio, one audio language, loudness -24 LKFS +/- 2, true peak max -2 dBTP, and zero start timecode. Missing metadata is marked Missing Info. Head/tail black and direct loudness measurement still require media analysis beyond the browser checker.

Profile Switching

The Mac app can switch between the official VOD 2026 profile, Original TE CHECK - Strict, the previous V1.9 Lite behavior, and any custom profile you save from Settings. The browser screen remains useful for pasted metadata exports only.
